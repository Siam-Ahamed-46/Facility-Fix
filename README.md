# FacilityFix --- University Facility Issue Reporting System

## 1. Project Overview

FacilityFix is a web-based application for reporting and managing
university facility issues. It helps users submit issues and allows
authorized users to manage assignments, track status updates, review
feedback, and view reports.

## 2. Technologies Used

-   PHP
-   HTML, CSS, and JavaScript
-   MySQL
-   XAMPP for local development

## 3. Main Features

-   User registration and login
-   Facility issue submission
-   Issue assignment and status tracking
-   Department-based issue management
-   Issue status history
-   Reviews and ratings
-   Reports and analytics

*Note: This list should match the functionality actually implemented in
the submitted code.*

## 4. Requirements

-   XAMPP with Apache, PHP, and MySQL
-   A modern web browser

## 5. Installation and Setup

1.  Install XAMPP.
2.  Extract the project folder into the XAMPP `htdocs` directory.
3.  Start Apache and MySQL from the XAMPP Control Panel.
4.  Open phpMyAdmin in your browser.
5.  Create a database named `spdd_faci_upd` if the SQL file does not
    create it automatically.
6.  Import the project's SQL file (expected location:
    `database/spdd_faci_upd.sql`).
7.  Configure the database connection in the project's existing
    configuration file.
8.  Open `http://localhost/spdd_faci_upd/` if your extracted folder is
    named `spdd_faci_upd`. Otherwise, use the actual folder name in the
    URL.
